# Orbital Smash: Ball Knockdown

بازی سه‌بعدی اندروید با Godot 4.3 و GDScript. با کشیدن و رها کردن انگشت توپ پرتاب می‌کنید و سازه‌ها را با فیزیک واقعی خراب می‌کنید.
(مکانیزم الهام‌گرفته از ژانر «Knock Balls» است؛ هیچ دارایی، نام یا مرحله‌ای از بازی اصلی کپی نشده.)

**سازنده: محمدطاها طاهریان**

## قابلیت‌ها
- ۳۰ مرحله در ۵ جهان (جزیره رنگین‌کمان، شهر نئونی، معبد باستانی، سرزمین یخی، فضای کیهانی) — هر مرحله یک فایل JSON در `data/levels/`
- ۵ نوع توپ: معمولی، سنگین، جهنده، انفجاری، دقیق (باز شدن با پیشرفت)
- ۶ ماده: چوب، شیشه، سنگ، فلز، لاستیک، کریستال — مشخصات در `data/items/materials.json`
- شرط‌های برد: نابود کردن کریستال‌ها، انداختن برج، پرت کردن بلوک‌ها از سکو؛ بلوک‌های قرمز «محافظت‌شده»
- ستاره (۱ تا ۳)، سکه، فروشگاه (رنگ توپ و رد نور)، ذخیره پیشرفت (`user://save.json` با نسخه پشتیبان)
- مسیر نقطه‌چین پرتاب (با برخورد واقعی)، لرزش دوربین، ذرات، صدا و موسیقی تولیدشده با کد (بدون فایل صوتی و بدون مشکل مجوز)
- انتخاب زمان روز (روز / غروب / شب) و ۱۰ محیط طبیعی (جزیره، جنگل، پاییز، بیابان، ساحل، برفی، کوهستان، معبد، شهر نئونی، فضا) در تنظیمات؛ تغییر سریع روز/شب از منوی توقف
- فارسی/انگلیسی، تنظیم کیفیت و جلوه‌ها، بدون اینترنت

## نسخه‌ها
Godot **4.3-stable** (GL Compatibility)، JDK 17، Android SDK platform 34 / build-tools 34.0.0.

## اجرا روی ویندوز ۱۱
1. Godot 4.3 را از godotengine.org دانلود کنید (نسخه Standard، نه .NET).
2. Godot را باز کنید ← Import ← فایل `project.godot` ← Run (F5).
3. یک‌بار هم `python tools/validate_levels.py` را بزنید تا مراحل بررسی شوند.

## ساخت APK با GitHub Actions
```
cd orbital-smash
git init -b main
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/<USERNAME>/orbital-smash.git
git push -u origin main
```
بعد در GitHub: تب **Actions** ← «Build Android APK» ← **Run workflow**. پس از پایان، در پایین صفحه اجرا در بخش **Artifacts** فایل `OrbitalSmash-Android-APK` (شامل `OrbitalSmash.apk`) را دانلود کنید. APK را روی گوشی نصب کنید (نصب از منابع ناشناس را فعال کنید).

## نسخه Release امضاشده
کلید را هرگز در مخزن نگذارید. در Settings ← Secrets این‌ها را بسازید: `ANDROID_KEYSTORE_BASE64`، `ANDROID_KEYSTORE_PASSWORD`، `ANDROID_KEY_ALIAS`. اگر `ANDROID_KEYSTORE_BASE64` تنظیم باشد، Workflow علاوه بر APK آزمایشی (debug)، `OrbitalSmash-Android-Release-APK` را هم می‌سازد. (AAB فعلاً پشتیبانی نمی‌شود؛ نیاز به Gradle build دارد.)

## افزودن مرحله / توپ / بلوک
- مرحله: `tools/generate_levels.py` را ویرایش و اجرا کنید، یا فایل `data/levels/level_31.json` را دستی بسازید (ساختار مثل فایل‌های موجود). با `python tools/validate_levels.py` بررسی کنید.
- ماده جدید: ورودی تازه در `data/items/materials.json` (و نام آن در `LevelValidator.MATERIALS`).
- توپ جدید: ورودی در `data/items/balls.json`، نام نمایشی در `scripts/core/loc.gd`، و در `GameState.BALL_ORDER`.

## کنترل
انگشت را روی صفحه بگذارید و به عقب بکشید (جهت = برعکس کشیدن، قدرت = طول کشیدن، کشیدن به پایین = زاویه بالاتر) و رها کنید.

## فونت فارسی
برای نمایش مطمئن فارسی روی همه گوشی‌ها، فونت Vazirmatn (مجوز OFL) را با نام `assets/fonts/Vazirmatn.ttf` اضافه کنید؛ بازی خودکار از آن استفاده می‌کند. در غیر این‌صورت فونت سیستم اندروید استفاده می‌شود.

## وضعیت آزمون (صادقانه)
- انجام‌شده: تولید و اعتبارسنجی ۳۰ مرحله با اسکریپت پایتون (ساختار، مرز سکو، نبود هم‌پوشانی بلوک‌ها).
- **انجام‌نشده**: اجرای Godot، اجرای بازی، ساخت APK، اجرای Workflow و تست روی دستگاه. محیط ساخت این پروژه Godot نداشت و اینترنت نبود؛ پس ممکن است خطای تایپی یا سازگاری در GDScript یا Workflow باشد. مرحله `tests/load_scripts.gd` در CI همین خطاها را نشان می‌دهد.
- توازن سختی، عددهای فیزیک (آستانه شکست، سرعت پرتاب) و ثبات برج‌ها نیاز به بازی‌کردن و تنظیم دارد (`materials.json`، `balls.json`، ثوابت بالای `game.gd`).
- ممکن است خطای Android SDK در اولین اجرای CI رخ دهد؛ لاگ مرحله «Export debug APK» را بفرستید تا رفع شود.
